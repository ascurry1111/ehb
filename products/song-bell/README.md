# Song Bell

A simpler 3D-printed bell that plays a song on its own — no companion
receiver, no phone, no transmitter/receiver pair. Print the body, add the
electronics, and it plays a tune by itself.

**Status: planned.** Nothing has been designed yet; this folder is
scaffolding, kept separate from
[`../electric-handbell`](../electric-handbell/) so this product's files
never mix with that one's.

## Anticipated layout

Following the convention used by
[`../electric-handbell`](../electric-handbell/):

```
3dprint/    OpenSCAD model for the bell body
firmware/   Microcontroller firmware for on-board song playback
```

Add a `CHANGELOG.md` here once there's a first release to log. Adjust the
layout above as the actual design takes shape — it's a starting point, not
a commitment.
